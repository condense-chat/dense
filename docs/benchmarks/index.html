Context compression benchmarks

Explore coding-agent replays, task completion, compressor evaluations and production results. Each study includes the workload, measured outcome and source.

Cost replays and task completion

  • Haiku 4.5 with a 190k context cap

    Three compression strategies on six SWE-chat sessions. Across its 1,600 matched turns, Condense saved 50.7% of input tokens and 28.0% of model cost.

  • Haiku 4.5 with uncapped context

    On 2,909 matched turns, Condense saved 37.3% of model cost. The shortest prompts cost more, and long contexts drove the savings.

  • Opus 4.8 across 64 coding sessions

    Across 11,712 turns, estimated model cost fell from $861.28 to $312.20 with Condense. Headroom cache mode raised it to $878.31.

  • Does the agent finish the task?

    Verifier results on long Terminal-Bench tasks, next-step scoring and a separate trial where compression increased cost.

Compressor evaluations and field results

These studies measure different things, from question-answering accuracy to the cost of a production agent. Each entry links to its source.

  • Published session replay
    A 938-turn coding session ↗

    One coding trace that exceeded 800k tokens of context was replayed for 938 turns. At Sonnet rates the estimated model cost went from $154 to $43, a reported 72.3% reduction.

    One unusually long trace. Helene 1 and Adeline 1 ran live; model costs were priced from cache-tier usage at Anthropic list rates. The Sonnet and Opus rows are the same session.

  • Usage analysis
    Where long sessions spend their tokens ↗

    Across 12 coding sessions and 18,333 assistant turns, cache reads accounted for 67.7% of the baseline model cost.

    A breakdown of the sampled workload, not a savings percentage or a separate compression trial.

  • Exploratory third-party tool comparison
    RTK on Terminal-Bench ↗

    In one Terminal-Bench comparison, cost per suite pass rose from $25.46 without RTK to $29.33 with RTK (+15.2%).

    No Condense arm. One run per setting; task outcomes vary across repeats. This measures suite cost rather than shell-output compression.

  • Standalone compressor · multilingual QA
    Helene 1.1 on Lost in Compression ↗

    At the roughly 50%-text-retained band, Helene 1.1 scored 7.09 accuracy points above bear-2 on the multilingual QA comparison.

    3,000 paired items across ten languages. Retained-text rates were approximately matched: Helene kept 1.02 percentage points more text than bear-2 at this band. This measures answer accuracy, not coding-agent solve rate.

  • Standalone compressor · conversational QA
    Helene 1 on CoQA ↗

    Across 150 CoQA turns, auto mode removed 30.6% of input tokens and scored 92.0% judged accuracy, versus 90.0% on uncompressed text.

    GPT-5.4 answered and judged the same 150 turns. The observed two-point difference represents three answers; no statistical significance is established.

  • Standalone compressor · long-document QA
    Helene 1 on LongBench v2 ↗

    On 150 LongBench v2 items, Helene 1 auto removed 38.8% of 15.7M input tokens. Measured accuracy was 49.3%, versus 48.7% on uncompressed text.

    One sample, one answerer/judge pairing. The accuracy difference is approximately one item. The separate 50-item code/structured-data figure is a subset of this test.

  • Standalone compressor · fact retention
    Adeline 1 on CoderForge SWE traces ↗

    On held-out CoderForge coding traces, Adeline 1 retained 94.2% of atomic facts while removing 90.2% of Claude-token input.

    Inputs were 30k–100k tokens. Fact recall measures information retained in compacted traces, not task completion or a reduction in model cost.

  • Production customer case study
    Axiometa Studio ↗

    Median cost per Studio turn, including failed turns, went from $0.45 to $0.16. Axiometa reports a 65% reduction.

    Before/after customer deployment combining compression, managed caching and changes to the agent workflow. The 65% cannot be attributed to compression alone.
