Cost / matched turns

Condense vs. Headroom

On the same 1,571 coding-agent turns, Condense saved 27.5% of model cost. Headroom cache mode saved 13.8% and Headroom Kompress saved 1.8%. All three started from the same $17.63 baseline.

Quality / task completion

Does the agent still finish the task?

A cost replay holds the conversation fixed. To test quality, let the agent choose its next step or run the entire task against its verifier.

What the verifier measured

Claude Opus 4.8 attempted 14 long Terminal-Bench tasks. Condense passed 11 of 14 trials and Headroom passed 10 of 14. The sample is too small to establish a winner.

What the next-step scores measure

On 192 shared steps, Condense chose the recorded action 24% of the time versus 46% for the control. A judge rated 63% and 58% of steps useful, respectively. Multiple actions can advance the same task.

Get started / dense CLI

Try it on your next session.

Install dense on a machine where you already use a supported coding agent.

macOS or Linux

curl -fsSL https://cli.condense.chat/unix | sh
Windows PowerShell
irm https://cli.condense.chat/nt | iex

Sign in during setup. For a one-session trial, uncheck preselected agents with Space, then press Enter. If setup asks about Claude Desktop, leave it on No. Launch the agent you use:

dense claude
dense codex
dense opencode

Run /dense:info inside the agent to see session usage. CLI guide · Condense pricing
