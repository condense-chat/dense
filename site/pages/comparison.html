Why match turns across all three strategies?

Some strategies completed more of the replay. The harness pairs each successful turn with its uncompressed baseline. Its published summary uses all available pairs for each strategy. For the comparison above, we took the intersection of session ID and turn index across all three strategies. Each row therefore prices exactly the same history.

Does the result carry over to Opus?

In a separate 64-session Claude Opus 4.8 rewrite replay, Condense reduced estimated model cost by 63.8%. Headroom cache mode increased it by 2.0%. Both used simulated cache pricing across 11,712 turns. The uncapped Haiku run tested only Condense, so its 37.3% savings measure a different question.
